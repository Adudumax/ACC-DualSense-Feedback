# L2 支撑测试版

版本：`1.2.0-preview.4-griploss.3-l2.2`，2026-10-25。

反馈行为以固定的 `1.2.0-preview.4-griploss.3` 为基线，保留 `brakeprobe.1` 的可选记录能力。不是在 `l2.1` 的轻前段曲线上继续叠加。原 `.3`、`l2.1` 和 `brakeprobe.1` 的程序、ZIP、源码归档及个人设置均不覆盖。

## 本版调整

### 常态 L2

自定义模式 L2 阻力为 50 时，从浅到深的十个协议位置区：

```text
固定 .3：[3,4,4,5,5,6,6,7,7,8]
本版    ：[3,4,4,5,6,6,7,7,8,8]
```

前四区保留原支撑，中后段三个位置各提高一档，让较高档位覆盖更多位置。不增加输入死区、不改刹车输入曲线，也不按减速度或轮胎状态动态改变常态阻力。松刹使用同一条位置曲线。

仍使用原有强度缩放。**本版没有解决高参数下多个位置提前封顶的问题**；阻力 100 时为 `[4,5,5,7,8,8,8,8,8,8]`。这是本轮保留的限制，避免同时引入新的强度映射或让高参数下某些位置弱于 `.3`。位置区不是校准后的等分物理行程，档位不等于实际反力。

### ABS 期间的 L2

原实现从第 2 区开始使用同一幅值的 15 Hz 硬件脉冲。本版在基础阻力与 ABS 都开启时，仍用原来的模式、频率、门槛及包络，改为随位置向后增加的脉冲幅值分布。

- ABS 参数继续影响整个事件幅值；L2 基础阻力参数影响向后增加的幅度。
- 两项参数都作用在最终量化之前，避免极低 ABS 参数先被提升到最小档再放大。
- 只开 ABS、基础阻力为 0 时，输出与原版逐字节一致。
- ABS 参数为 0 时，游戏触发 ABS 也不输出本插件 ABS 脉冲，保留本版常态 L2。
- 两项都为 0 时，不输出上述两种 L2 效果。独立抱死参数仍按原逻辑工作。

例如 L2 阻力 50、ABS 脉冲 50，事件包络充分建立时：

```text
原 ABS 幅值：[0,0,5,5,5,5,5,5,5,5]
本版幅值  ：[0,0,5,6,6,6,7,7,8,8]
```

**这是分区振动候选，不是把基础阻力与振动独立叠加。** `0x26` 振动幅值与 `0x21` 阻力档位不能直接换算为反力；本版尚未经过实机确认，不能仅凭上面的数字声称已经保住原反力。如果实际只有振动变强、按压支撑仍明显变空，应否决这个候选，再单独研究同一阻力模式中的有限调制。

## 保持原输出

- R2 常态阻力、TC 40 Hz、空转 7 Hz、升挡提醒 18 Hz、实际换挡冲击 28 Hz及原优先级。
- ABS/抱死信号判定、机械备用目标、原包络、ABS 握把辅助；活跃抱死提示仍为原 8 Hz 命令。
- `.3` 轮胎反馈、后轴失抓拖拽、左右路肩/草地定位、引擎、原生和碰撞握把反馈。
- 刹车/油门输入字节直通、陀螺仪、灯光、遥测、输出线程、HID 写入频率、native DLL、设置格式和默认参数。

新逻辑只做固定十区的栈上计算，不增加采集字段、后台线程或普通运行的文件读写。普通游戏、启动确认、手动扳机诊断及可选记录使用同一份新 L2 常态曲线。

## 测试顺序

1. 解压到新目录，退出其他版本。打开本版，自定义模式设 **L2 阻力 50、ABS 脉冲 0，其他反馈参数为 0**。保留平常使用的输入/陀螺仪设置；游戏 ABS 可以开启。完成轻刹、中段保持、重刹及平顺松刹。
2. 只把软件 **ABS 脉冲改为 50**，游戏 ABS 开启，其他反馈保持 0。正常完成轻、重刹，观察 ABS 进入/退出时是否仍明显失去支撑、是否容易稳定保持及松开刹车量。ABS 参数包含原有握把辅助，所以此时握把不一定完全静止。
3. 前两步没有明显问题后，恢复个人常用的其余反馈，确认稳定效果仍熟悉。不要用其他 R2 提示与 L2 的数值大小来推断实际反力。

不要求辨认一档阻力的细微差异，只需判断是否更容易控制，以及 ABS 时是否还明显变空。若更突兀、只增加振动而没有帮助控制，直接回退原 `.3`。本轮不强制再采相同记录；需要记录时，退出普通程序后运行附带的 `Start Brake Capture.cmd`，按 Ctrl+C 正常结束。
