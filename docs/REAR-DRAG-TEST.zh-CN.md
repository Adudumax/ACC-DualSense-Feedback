# 后轴拖拽测试：1.2.0-preview.4-griploss.3

基准为 `1.2.0-preview.4-tcgrip.4`，本版只在明确后轴失稳时加入 griploss.1 的后轴拖拽声部。普通驾驶、正常过弯、前轴反馈和没有后轴失稳的路肩/草地继续使用基准输出。没有新增前轴纹理，也没有 griploss.2 的声部替换路径。

## 这次保留的质感

在事件开启期间保留 griploss.1 后轴声部的完整设置：36 Hz 幅度调制、64% 持续底纹、4.5 Hz 轻起伏、12 ms 起振与 100 ms 释放时间常数，左/右增益 0.52 / 0.31，以及基准混音之后、碰撞之前的附加方式。声部强度也使用 .1 的后轴映射，不再乘 .2 的小替换权重。

上述频率是软件幅度调制，不等于执行器物理频率；公式数值保留不等于已经证明实际手感完全相同。事件资格比 .1 保守，触发时点仍需实测。

## 触发与退出

采用独立事件资格：后轴侧滑超过普通背景，并有双后轮或明显车身横移佐证。单轮压路肩/草地造成的异常本身不能开门；真实单轮失稳伴随车身横滑仍允许触发。单纯 TC 介入、直线空转或油门开度不能替代后轴横滑证据。

收油后若车尾仍在横滑，拖拽会继续。只有明确证据可持续续期，弱恢复证据最多连接约 180 ms，之后还有 100 ms 时间常数的包络释放，避免正常长弯无限维持拖拽。遥测冻结、无效运动、低速或关闭失抓参数会清理新增声部。

## 左右感觉的约定

后轴偏左是保留原拖拽的触觉标签，不表示车辆向左甩尾。真正失抓及其短暂释放尾巴期间，拖拽可以盖过同时发生的路肩左右感觉；这属于本次有意保留的取舍。没有事件时新增层为零，不改变基准路肩定位。

TC、L2/R2、原轮胎、路肩、原生震动、引擎和碰撞的原计算保持 tcgrip.4。拖拽不回写共享滑移估计、左右归属、发动机让位或 TC 遮罩。

## 验收顺序

1. 同车同赛道、同一组参数与 tcgrip.4 对比：正常行驶、普通过弯、左右路肩和草地。先确认没有后轴失稳时，未出现额外左侧拖拽或轮胎独占握把。
2. 仅保留“轮胎失去抓地力”50，其他震动关闭，测试关闭游戏 TC 的出弯甩尾、松油、反打和恢复。与 griploss.1 比较拖拽质感是否回来、是否触发太晚、恢复后是否有残留。前轴推头仍是原版反馈。
3. 恢复常用全开参数，核对拖拽能否辨识，TC/空转/换挡/ABS是否仍按原表现工作。明确后轴失稳与路肩同时发生时，不要求保持纯路肩的左右感觉。

现有“轮胎失去抓地力”参数同时控制原轮胎反馈和新增拖拽，建议先用 50，不增加新滑块。测试版应解压到新目录，每次只运行一个版本；可直接退出后运行原 tcgrip.4、griploss.1 或 griploss.2 对照。此前安装包和配置没有被覆盖。
