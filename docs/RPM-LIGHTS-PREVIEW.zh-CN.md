# 灯光与启动反馈预览：1.1.0-preview.6

继续使用 ViGEmBus，交付中英文自包含便携 ZIP；已发布 1.0.1 包保持原样。

1. 解压到新目录，两个版本不要同时运行。
2. 可复制原有 ACCDualSenseFeedback.settings.json，震动/扳机参数格式不变。
3. 高级设置的“06 灯光反馈”只保留总开关和平滑/分段选择，均有短过渡动效。
4. 可复制旧 ACCDualSenseFeedback.lights.json；旧总开关关闭或亮度为零的状态会保持关闭。
5. ACC 尚未运行时，首次连接手柄会按正式版 v1.0.1 的基础曲线建立扳机阻力约 120 ms 后释放，力度跟随各侧基础阻力设置。每次软件启动最多一次，重连/重新检查不重播；ACC 已运行时跳过，驾驶反馈到来立即让位；某侧基础阻力设为 0 时该侧不动作。
6. 发动机运行后，停车、松油且处于低转速时以冰蓝色（#5AAFD6）缓慢呼吸；离开怠速平顺回到转速颜色。低转速行驶仍为绿色稳定底光。
7. 加速时逐渐增亮，颜色绿→黄→红，五颗白灯逐级点亮。最大转速 97% 处开始约 3 Hz RGB 闪烁，这是通用提示线，不是车型最佳升挡点。
8. 正常速度制动、收到 ABS 振动量时，RGB 短暂约 4 Hz 闪黄。轮速和纵向滑移共同满足保守条件时，也提示疑似锁死；白灯继续显示转速。
9. 倒挡显示白色；发动机停止、回放、关闭灯光或遥测失效时清除灯光。

本轮实测重点：启动阻力与声响是否接近旧版、约 120 ms 后是否释放、重连/重新检查是否不重播。
灯光沿用 preview.5，怠速亮度/呼吸、低转持续有光、ABS 提示与误闪仍可按原流程复查。
锁死提示需要先有正常滚动数据以建立轮速参考；轮速缺失时不凭打滑量单独制造锁死警告。

本版围绕 ACC 设计，不再追求严格等同 CSP。按讨论保持当前驾驶提示范围，不加入低油、起步倒计时、排火、TC 和旗语。

[当前详细规则、阈值和验证边界](ACC-LIGHTING.zh-CN.md)

本轮只替换独立启动确认的阻力曲线；Runtime 接入、Haptics、Telemetry、Hardware 和 Lighting 均保持 preview.5 原样，正常驾驶发送条件不变。
旧帧保护保留，启动确认不伪造遥测或 ACC 状态。[启动确认细节](STARTUP-CONFIRMATION.zh-CN.md)
preview.4 已获用户实测正常反馈；preview.5 包同样保留。preview.6 的启动力度需实机验收，不能保证与旧版响声完全一致。
