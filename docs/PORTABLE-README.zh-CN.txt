ACC DualSense Feedback 1.1.2 · 简体中文版
========================================

为 Assetto Corsa Competizione 增强 DualSense 震动与自适应扳机反馈的小工具。
解压后直接运行 EXE，无需安装本工具、.NET 运行时或中文字体。

使用条件

- Windows 10 / Windows 11，64 位。
- PC 版 Assetto Corsa Competizione（ACC）。
- DualSense / DualSense Edge；建议 USB 连接，其他连接方式自行测试。
- 已安装 ViGEmBus 虚拟手柄驱动。
- 关闭 ACC 的 Steam Input；本工具运行时完全退出 DS4Windows。

ViGEmBus 官方下载：
https://github.com/nefarius/ViGEmBus/releases

用户需要安装的是 ViGEmBus，不是 ViGEm.NET；后者已集成在本工具中。
HidHide 不是必需安装项。如果电脑已启用 HidHide，请在 Applications
列表中允许当前路径下的 ACCDualSenseFeedback.exe 访问实体手柄。
如果出现实体与虚拟手柄重复输入，再根据需要使用 HidHide。

首次使用

1. 将 ZIP 完整解压到可写目录，不要直接在压缩包中运行。
2. 如未安装 ViGEmBus，请先安装驱动。
3. 连接手柄，退出 DS4Windows，关闭 ACC 的 Steam Input。
4. 打开 ACCDualSenseFeedback.exe，再启动 ACC 并进入驾驶。

条件齐全时反馈自动运行。关闭本工具会安全停止反馈与虚拟手柄。
仅关闭窗口才是退出；最小化时工具仍在运行。

启动确认

ACC 尚未运行时，首次成功连接手柄会按正式版 v1.0.1 的基础阻力曲线建立
扳机阻力约 120 毫秒后释放；力度跟随各侧当前基础阻力设置，支持自定义增强。
确认输出通道可响应。每次软件启动最多一次；重连或“重新检查”不重播。
如果 ACC 已运行则跳过，驾驶反馈到来时立即让位。某侧基础阻力调为 0，
该侧也不执行启动动作；握把电机不参与。该提示不能证明游戏遥测已生效。
保留游戏进程检测、首帧验证和超时清除，不读取旧帧来制造启动提示。

反馈调校

默认预设使用经过调校的参数。进入“高级设置”后，可独立调整各项反馈。
强度参数为 0–100，调至 0 即关闭；右键点击参数行可恢复该项默认值。
重要：“红线脉冲起点”保持默认 96.2%，已支持车型才会自动使用原生
仪表报警转速。修改后，R2 改用最高转速 94.0%–99.0% 的手动比例，
灯光恢复 97% 通用参考，二者可能不再匹配仪表。右键该行可恢复默认。
调整力度请使用独立强度控件。

本版内置 55 个车型原生参数，自动识别车辆，无需手动选车或额外后台解析。
未知车型或限转值不匹配时沿用通用规则。匹配车型在六挡不触发自动升挡
报警；输入转发、主震动、基础扳机阻力与其他反馈机制保留。
修改即时生效并切换到自定义预设。参数保存到 EXE 同目录的
ACCDualSenseFeedback.settings.json；该文件首次保存时自动生成。
中文与英文版本使用相同的参数格式，反馈算法及默认强度保持一致。

灯光反馈

进入“高级设置”，向下滚动到“06 灯光反馈”。只保留总开关和“平滑／分段”
模式，开关与模式选择使用项目现有样式及短过渡动效。

发动机运行时有低转速底光；停车怠速以冰蓝色缓慢呼吸，基色 #5AAFD6。
离开怠速平顺回到原转速颜色；低转速行驶保持绿色稳定底光。平滑模式
使用 HSV 色相，分段模式显示绿、黄、红。
五颗白灯逐级表示转速，硬件亮度自动调整。自动适配的车型以原生仪表
报警转速作为五灯全亮和 RGB 升挡提示的参考点；通用模式使用最大转速
97%。RGB 保留约 3 Hz 的闪烁节奏，不保证每次闪烁相位与仪表重合。

正常速度制动且收到 ABS 反馈量时，RGB 约 4 Hz 闪黄。轮速明显降低和
纵向滑移持续满足条件时也提示疑似锁死；白灯继续显示转速。锁死是
保守推断，需要先有正常滚动数据；缺少轮速时不单凭打滑量触发。
倒挡显示白色；停机、回放、关闭灯光、遥测失效或退出时清除灯光。
本版不加入低油、起步倒计时、火焰、TC 或旗语。详细规则见源码仓库
中的 docs/ACC-LIGHTING.zh-CN.md。

设置独立保存在 EXE 同目录的 ACCDualSenseFeedback.lights.json，
旧版总开关关闭或亮度为零的选择会保持关闭。反馈设置、力度校准与
正常驾驶的 HID 发送条件保留。
CSP 原实现的 MIT 许可已包含在 licenses 文件夹。

遇到问题

- 未检测到手柄：检查手柄连接与 HidHide 应用访问权限。
- 反馈不可用：检查 ViGEmBus、手柄连接与 HidHide。
- 需要处理：退出 DS4Windows，再点击“重新检查”。
- 等待驾驶：ACC 已启动，但尚未收到有效驾驶遥测，请进入驾驶。

打开“诊断与日志”，点击“复制诊断报告”，将完整报告发给开发者。
报告保留详细的驱动与运行信息；技术字段和异常原文保留英文，便于诊断。
运行日志只保存在内存中，不持续写入磁盘。导出的报告会脱敏用户目录与
私密 HID 设备路径，包括异常原文中出现的路径。

此 EXE 尚未数字签名，Windows SmartScreen 可能提示未知发布者。
本包不包含遥测录制脚本、自动验证程序、个人设置或测试数据。
