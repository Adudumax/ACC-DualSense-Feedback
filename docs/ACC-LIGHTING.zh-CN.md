# ACC 专用灯光：1.1.2

沿用已发布版的低转速底光、冰蓝怠速呼吸、ABS/疑似锁死闪黄与启动确认。
本版增加内置车型原生报警参数，R2 升挡提醒和灯光共用同一报警参考点。
以 ACC 实际输入和可辨识性为准，不再以完整复刻 CSP 为目标。
设置仍只有 Enabled 与 Smooth/Discrete，格式、现有样式和动效保持不变。

## 正常转速与怠速

有效遥测、发动机运行、RPM>0、static.maxRpm 合理时输出；发动机停止或回放清除。
灯光的视觉比例以 static.maxRpm 为基准；原生报警参数仅在车型 ID、静态限转值与物理页限转值均匹配时使用。

- 低转速行驶为绿色底光，亮度约 10%。速度低于 3 km/h、油门低于 4%、RPM 低于最大值 30% 时启用冰蓝色呼吸，基色 #5AAFD6，三秒周期，约 6%–14% 的基色强度，始终有光。
- 呼吸状态与颜色以 0.3 秒时间常数过渡，尾部低于 0.5% 时归位；首次在怠速启动直接显示冰蓝色。离开怠速回到原转速色，RPM 在最大值 30%–45% 间逐步排除冰蓝色，高转速与警告不混入冰蓝色。行驶中松油不单独触发呼吸。
- 亮度在最大转速 35%–65% 间以 smoothstep 连续增至全亮，移除原先约 50% 最大转速以下全黑的区间。
- 通用颜色区间为最大转速 60%–97%。平滑模式 HSV 120°→0°，绿→黄→红；分段模式在区间进度 50%、82% 分别切至黄、红。
- 通用模式五颗白灯阈值为最大转速 60%、69.25%、78.5%、87.75%、97%，等于阈值即点亮；97% 时五颗全亮。
- 白灯亮度随区间自动调整，原报告编码保持低=2、中=1、高=0。
- 通用模式 RPM 达到最大值 97% 时 RGB 约 3 Hz、50% 占空比红/黑闪烁，新警告从亮相位开始；底光不填补黑相位。
- 倒挡显示白色，白灯仍显示转速。暂停冻结动画及新制动判定；回放清除。

以上百分比描述通用回退规则。默认 96.2% 起点下，已匹配车型改用 ACC 1.10.4 原生 CarData.EngineData.RpmLimiterAlarm，颜色与白灯区间从最大转速 60% 延伸到这一报警点。内置 55 个车型参数，不扫描游戏文件；只在车型 ID 变化时查表。原生报警采用严格大于比较，保留 80 rpm 退出滞回，并在六挡（原始挡位 7）、空挡、倒挡、熄火、暂停和回放时停止自动报警。

修改“红线脉冲起点”会退出原生适配：R2 使用手动比例，灯光恢复上述 97% 通用参考。未知车型或任一路限转值不匹配也回退通用规则。原始遥测、R2 力度/频率/包络、其他反馈优先级与灯光闪烁节奏保留。

参数是原生 HUD 报警点，不是宣称的理论最佳换挡点或实时 HUD 闪烁信号。数据来源版本不是启动限制；新增车辆未收录时仅该车回退。未来若游戏改变既有报警数值，仍需更新参数表。

## 制动闪黄

灯光自己的 `AccBrakeLightDetector` 使用现有只读快照。不读取用户震动强度，不从最终电机/扳机输出反推事件，不修改震动判定。

ABS 提示要求速度至少 12 km/h、刹车至少 16%、有限的 absVibration 绝对值至少 0.06。
AbsLevel/TcLevel 是辅助设置，不是介入状态；本版也不依赖 ACC 标注未使用的 AbsInAction。
absVibration 是游戏提供的 ABS 反馈量，不是对液压动作的直接测量，仍需实际车型/设置验证。

疑似锁死的保守判定：

1. 先在至少 20 km/h、低刹车、非大油门、近似直行、低纵向滑移且四轮滚速合理时，学习每轮角速度/车速参考，不假设固定轮胎半径。
2. 制动时要求至少 20 km/h、刹车至少 16%、油门低于 20%、该轮纵向滑移绝对值至少 0.15，且角速度低于参考滚动速度 72%。
3. 若有效轮载显示明显卸载，不把该轮作为锁死证据；轮载缺失时不编造轮载。
4. 需跨不同物理包持续至少 60 ms；重复包不确认，超过 120 ms 的采样间隙重新确认。

锁死是推断，不能声称完全等同游戏内部真值。缺少滚动参考或轮速时，不单凭滑移触发。
任一事件成立，RGB 约 4 Hz 黄/黑闪烁，最后一次新物理包的事件后保留 180 ms；重复包不会无限续期。
五颗白灯继续显示转速，颜色不混合。

正常驾驶的 RGB 优先级：制动黄闪 > 倒挡白色 > 换挡红闪 > 转速/底光。
事件结束恢复当前转速。最大转速变化、重连、关闭灯光或停机时清除内部校准和事件状态。

## 范围与隔离

preview.5 除冰蓝色外，按用户要求在 Runtime 中接入独立的一次启动确认。
HID 编码、游戏内震动计算、扳机曲线、桥接、遥测读取与旧帧保护保持原样。
preview.6 开始时记录源文件 SHA-256，完成后核对除 StartupTriggerConfirmation 和版本声明外的源文件未变。
灯光仍搭载合并报告，不增加灯光专用写入；启动动作通过同一线程执行，正常驾驶发送条件不变。
详见 [启动确认与验证边界](STARTUP-CONFIRMATION.zh-CN.md)。

按讨论保持当前驾驶提示范围，不加入低油、发车倒计时、排火、TC 或旗语。

## 验证与实测

自动检查覆盖底光、呼吸周期/亮度、行驶不呼吸、转速边界、五白灯、闪烁相位、RGB 优先级、
ABS 门限、锁死确认/释放、轮速参考、侧滑/短路肩事件/明显卸载过滤、重复包/采样间隙、
暂停/回放/重置、设置迁移和触觉字节。原 CSP 862 个 Lua 样本继续验证保留的参考数学函数，
不用它们宣称新的 ACC 效果与 CSP 一致。

共享内存测试使用随机命名的测试页，不创建真实游戏共享内存。
中英文 WPF 以离屏方式检查布局、开关和动画，不启动真实手柄或虚拟设备。
还检查无游戏 dry-run、保护文件哈希和便携包版本/内容。

原生报警预览已获用户实车反馈通过，包括 Audi R8 LMS evo II、Ferrari 296 GT3、McLaren 720S GT3 Evo 与 Mercedes-AMG GT3 Evo 的测试记录。软件检查覆盖 55 个参数条目，但不代表全部车型或 BoP 变体都完成实车验证。
